# UTM Builder
A simple UTM builder. With options for channels, variables and parameters . This project is built as a single, standalone HTML file. Everything it needs (structure, styles, and scripts) lives inside that one file, so there is nothing to install, build, or configure. If you have a web browser, you can run it.

## About

This project is built as a **single, standalone HTML file**. Everything it needs (structure, styles, and scripts) lives inside that one file, so there is nothing to install, build, or configure.

If you have a web browser, you can run it.

## Features

- **No installation**: no dependencies, no package managers, no build step
- **Works offline**: once downloaded, it runs without an internet connection
- **Portable**: copy it to a USB drive, email it, or keep it on your desktop
- **Cross-platform**: runs on Windows, macOS, Linux, ChromeOS, Android, and iOS
- **Private**: runs entirely in your browser, nothing is sent to a server

## Getting Started

### Option 1: Download the file

1. Download `index.html` from this repository (open the file and click **Download raw file**)
2. Save it anywhere on your computer
3. Double-click the file to open it in your default browser

### Option 2: Use it online

If GitHub Pages is still active for this repository, you can also use it directly at:

```
https://lro-ui.github.io/UTM_Builder/
```
